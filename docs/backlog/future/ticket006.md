# FUTURE-006: Evaluate Gamification

## Type

Product Feature (Postponed)

---

## Priority

Low

---

## Phase

Long-Term

---

## Goal

Evaluate light gamification elements that reinforce consistency without turning
household work into competition.

---

# Background

Streaks, points and achievements were excluded from FRONTEND-007 and ANALYTICS-003.
The design principle "Consistency Over Intensity" argues against volume-based rewards.
Gamification can motivate but also create pressure, guilt or unfairness between members.

---

# Dependencies

```text
ANALYTICS-008
HOUSEHOLD-003
```

---

# Scope

## Candidate Elements

```text
Consistency milestones (e.g. "Mobility workout kept on schedule for 3 months")
Household achievements (shared, not individual)
Category "health" visuals (e.g. a plant that thrives)
```

## Explicitly Rejected

```text
Individual leaderboards
Points for volume
Penalties
```

## Evaluation

Prototype with the household for 4 weeks; decide based on feedback.
Gamification must be optional (setting, default off).

---

# Deliverables

```text
Concept document
Prototype (feature-flagged)
Decision
```

---

# Acceptance Criteria

- Concept aligned with design principles
- Optional and off by default
- Decision based on real usage

---

# Definition of Done

- Gamification decision made with evidence

---

# Out of Scope

- Rewards with monetary value
