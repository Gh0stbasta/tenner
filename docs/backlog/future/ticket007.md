## Goal

Decide whether a native mobile app (React Native, as listed in the architecture)
provides enough value over the PWA (MOBILE domain).

---

# Background

PWA limitations: iOS push only for installed PWAs, no widgets, limited background sync,
no Siri/Shortcuts integration, no Apple Watch.

Native app costs: App Store fees (99 USD/year Apple), review process, second release
pipeline, native push (APNs/FCM).
